# Прототипы Restar

Одноразовые прототипы интерфейса для показа команде. Это не код приложения: каждый прототип — статичная страница, её можно удалить, когда решение принято.

- `star-sky/` — главный экран без нижнего меню: в центре звезда «Око», вокруг звёзды разделов. Варианты: `?variant=A` (созвездие), `B` (орбиты), `C` (свободный полёт), `all` (три телефона рядом); `&still=1` — без движения.
